# XAUUSD Scenario Pro 📈

Aplikasi web berbasis Streamlit bergaya TradingView untuk analisis pergerakan harga Emas (XAUUSD). Dirancang khusus untuk memetakan skenario trading (Long-Term/Position) dan memantau fundamental tanpa adanya fitur auto buy/sell.

## Fitur Utama:
- **Multi-Timeframe Analysis:** Dari 15 menit hingga Bulanan.
- **Scenario Planner:** Simulasi garis Entry, Take Profit, dan Stop Loss beserta perhitungan Risk/Reward Ratio.
- **Advanced Indicators:** SMA, EMA, Bollinger Bands, Ichimoku, RSI, MACD, Stochastic.
- **Fundamental Tracker:** Menarik berita Emas terbaru dan panduan driver market secara real-time.

## Cara Menjalankan di Komputer Lokal:
1. Clone repository ini.
2. Install library: `pip install -r requirements.txt`
3. Jalankan aplikasi: `streamlit run app.py`
